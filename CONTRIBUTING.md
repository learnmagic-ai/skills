# Contributing

Thanks for looking. These skills are written for people who have just started making things with AI, so the most useful feedback comes from exactly those people.

## The easiest way to help

Open an [issue](../../issues/new/choose) and tell us what happened. You don't need to know why it went wrong. Useful things to include:

- Which skill, and what you typed or pasted.
- Which tool you used it in (Claude on the web, the desktop app, Claude Code).
- What you expected, and what you got instead.
- Anything in the skill's instructions that confused you. If you got lost reading a `SKILL.md`, that's a bug in the skill, not in you.

Please don't paste anything private. Replace names, numbers and addresses with made-up ones.

## Suggesting a change to a skill

Pull requests are welcome, but a few ground rules keep the skills safe for beginners:

1. **Keep them plain.** A skill is a folder with a `SKILL.md` a non-technical person can open and read. No programs to run, no hidden steps.
2. **Stay inside the lines.** A skill only works with what the person gives it. It must not install anything, change settings, send information anywhere, or change files without showing the change first and waiting for an OK.
3. **Work in a normal chat.** If a step needs extra tools (web access, files, helper agents), say so and give a way to do it without them.
4. **No personal or company details.** Examples should be generic.

Because of rule 2, every change to a `SKILL.md` is re-checked by fresh reviewers (injection, privacy, scope) before it is published on [learnmagic.ai/skills](https://learnmagic.ai/skills). That takes a little while, so please be patient if a pull request sits for a few days.

Changes to the README, this file, or other documentation don't need that review and are usually quick.
